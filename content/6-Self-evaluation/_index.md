I did my internship at **Amazon Web Services Viet Nam Company Limited (AWS Vietnam)** from **15/06/2026 to 14/08/2026** as part of the **Workforce Bootcamp - First Cloud AI Journey** program.

Looking back honestly, this was one of the most challenging and rewarding things I have done as a student. I went from knowing the basics of cloud concepts to building a full end-to-end SOC detection lab with real-time auto-remediation, a custom Elastic SIEM integration, SQL threat hunting over CloudTrail logs, and a React dashboard — all running on AWS with zero spending.

Throughout the internship, I tried to take ownership of my work and not just wait for instructions. There were moments of frustration — misconfigured IAM policies, Terraform errors that took hours to debug, EventBridge rules that refused to fire — but working through those problems taught me more than any tutorial ever could.

### What I Want to Improve Going Forward

* **Deeper threat analysis**: I want to get better at multi-stage cloud attack chains and more advanced adversary emulation techniques beyond what this lab covered.
* **Communicating technical findings clearly**: Being able to explain a complex security architecture to a non-technical manager or client is a skill I need to keep developing.
* **Scaling infrastructure**: I want to learn more about building IaC modules that can handle enterprise-scale log volumes without performance or cost surprises.
