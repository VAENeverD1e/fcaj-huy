# Phụ lục

Phụ lục này tổng hợp các liên kết đến các repository mã nguồn và mã hạ tầng dạng mã (Infrastructure as Code - IaC) minh họa cho toàn bộ công việc và sản phẩm kỹ thuật đã thực hiện trong suốt kỳ thực tập.

---

### Các Repository Mã Nguồn GitHub

#### 1. SOC Threat Detection & Incident Response Lab

* **Liên kết Repository:** [https://github.com/VAENeverD1e/soc-detection-lab](https://github.com/VAENeverD1e/soc-detection-lab)
* **Mô tả:** Mã nguồn và tài liệu kiến trúc cho phòng lab Phát hiện đe dọa an ninh Cloud và Tự động phản ứng sự cố trên AWS. Bao gồm các kịch bản tấn công giả lập.

#### 2. Operations Dashboard & Terraform Infrastructure

* **Liên kết Repository:** [https://github.com/KoangWy/ops-dashboard](https://github.com/KoangWy/ops-dashboard)
* **Mô tả:** Mã nguồn full-stack và kịch bản hạ tầng dạng mã (Terraform IaC) cho Bảng điều khiển Quản lý Sự cố An ninh & Vận hành (Ops Dashboard). Bao gồm giao diện React frontend, tích hợp API, cùng các kịch bản Terraform tự động khởi tạo hạ tầng AWS (DynamoDB, API Gateway, S3 hosting, và AWS Lambda).
